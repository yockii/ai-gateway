## <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| test code → production API | Tests MUST use mocked APIs or test environments |
| E2E tests → local dev server | Tests start their own dev server instance |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-06 | Spoofing | test credentials | mitigate | Use fake credentials in tests, never real ones |
| T-04-07 | Tampering | test data | mitigate | Each test uses fresh data, isolated test runs |
| T-04-08 | Information Disclosure | test screenshots | mitigate | E2E tests only screenshot on failure, sanitize sensitive data |
| T-04-09 | Denial of Service | dev server leaks | mitigate | Playwright automatically manages dev server lifecycle |
| T-04-10 | Escalation | test API access | accept | Tests only hit localhost or mocked endpoints |
</threat_model>
