## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff (white) | Background, surfaces |
| Secondary (30%) | #f4f4f5 (zinc-100) | Cards, sidebar background |
| Accent (10%) | #2563eb (blue-600) | Primary buttons, active states, links |
| Destructive | #ef4444 (red-500) | Delete buttons, error states, danger actions |

**Accent reserved for:**
- Primary action buttons (Create, Save, Submit)
- Navigation active states (sidebar, tabs)
- Links in text content
- Selected/checked states

**Semantic colors:**
- Success: #22c55e (green-500) — successful operations, positive indicators
- Warning: #f59e0b (amber-500) — warning messages, caution states
- Info: #3b82f6 (blue-500) — informational messages
- Error: #ef4444 (red-500) — error messages, validation failures

**Source:** shadcn-vue default zinc color palette with blue accent — industry standard for admin dashboards.

## Interactive States

### Loading States

| Component | Loading State | Implementation |
|-----------|---------------|----------------|
| Button | Spinner + disabled text | shadcn-vue Button: `:loading="true"` |
| Table | Skeleton rows | DataTable skeleton prop |
| Page | Centered spinner | Full-page loader with backdrop |

### Error States

| Type | Display | Recovery |
|------|---------|----------|
| Network error | Toast notification | Retry button in toast |
| Validation error | Inline red text | Clear on input |
| 401 Unauthorized | Redirect to login | Auto-redirect after auth fail |
| 403 Forbidden | Error page | Back to home button |
| 500 Server error | Error page | Retry button |

### Empty States

| Context | Display | Action |
|---------|---------|--------|
| No API Keys | Illustration + text | "Create API Key" button |
| No usage data | Empty chart placeholder | "Start using API" message |
| No bills | "No bills yet" | Link to pricing page |
| No users (admin) | Empty table | "Add User" button |

**Source:** Standard shadcn-vue state patterns + CONTEXT.md copywriting requirements.

## Form Patterns

### Form Validation

| Rule | Implementation |
|------|----------------|
| Required fields | `zod` schema validation | `*.required()` |
| Email format | `zod.string().email()` | Inline error on blur |
| API Key name | 3-50 characters | `zod.string().min(3).max(50)` |
| Concurrent limit | Number, min 1 | `zod.number().min(1)` |

### Form Layout

- **Label position:** Above input (standard shadcn-vue)
- **Help text:** Below input in muted color
- **Error text:** Below input in red, replaces help text
- **Submit button:** Right-aligned, primary variant

**Source:** CONTEXT.md D-07 (shadcn-vue built-in form validation).

## Implementation Notes

1. **Monorepo Structure:** `frontend/user/` and `frontend/admin/` are separate Vite projects with `frontend/shared/` for common components (CONTEXT.md D-01, D-02)

2. **API Client:** Encapsulated axios with JWT token management, request/response interceptors (CONTEXT.md D-04)

3. **Bill Export:** Backend async generation to S3/OSS, frontend displays download link list (CONTEXT.md D-08)

4. **Real-time Updates:** 30-second polling for dashboard data (CONTEXT.md D-12)

5. **Authentication:** JWT tokens stored in localStorage, added to Authorization header
