# AI Gateway 项目

## 项目概述

**项目名称**: AI Gateway Platform
**项目类型**: AI 大模型网关平台
**当前阶段**: Milestone 2 - 核心功能补全
**创建时间**: 2026-05-08
**最后更新**: 2026-05-11

## 项目描述

开发一款 AI 大模型网关平台，覆盖 OpenAI、Claude、Qwen 等大模型的调用。平台需打造一套代码调用多种大模型的一致性体验。

**状态**: ✅ 完成

- ✅ Phase 1: Bifrost 集成和基础架构
- ✅ Phase 2: 核心功能开发（数据模型、API 网关、处理器）

### Milestone 2: 核心功能补全 (2026-05-11 ~ 2026-05-11)
**状态**: ✅ 完成

**背景**: 经过需求与实现对比分析，发现以下核心功能缺失或不完整：
1. 定价体系：大客户独立定价、套餐价格应用逻辑
2. 供应商管理：API Key 管理、模型关联管理
3. 用户 API Key 管理：后端 CRUD 实现缺失
4. 模型路由：故障转移、性能监控待完善

## 核心目标

1. **统一接口**: 提供统一的 API 接口调用不同大模型（文本、图片、视频、TTS、Embedding、Reranking 等）
2. **模型管理**: 支持对外模型自定义和灵活配置
3. **价格体系**: 参考 Bifrost 的完善价格体系，支持多种计费模式（**M2 重点**）
4. **用户管理**: 完整的用户注册、登录和 API Key 管理（**M2 重点**）
5. **运维监控**: 账单管理、调用记录、数据导出
6. **网关路由**: 智能路由到不同供应商和模型（**M2 重点**）
7. **服务分离**: 用户端和运维端独立管理，API 网关独立部署

## 技术栈

- **后端**: Go 1.26.2
- **数据库**: PostgreSQL (已启动,端口 5432)
- **ORM**: GORM (自动迁移,禁用外键)
- **架构**: 微服务架构
- **前端**: Vue 3 + TypeScript + shadcn-vue
- **核心引擎**: Bifrost (D:/projects/github.com/maximhq/bifrost)

## 关键决策点

### 技术方案选择 (已确定)

当前采用**深度二次开发**模式：基于 Bifrost 进行大量定制，自建业务层

### Milestone 2 关键决策 (待确定)

1. **供应商 API Key 存储方案**: 加密存储 vs 密钥管理服务
2. **大客户定价实现**: 扩展现有模型 vs 新建独立表
3. **模型路由健康检查**: 主动探测 vs 被动监控
